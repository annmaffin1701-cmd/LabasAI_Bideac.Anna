# Crocodile Teeth — Minimax (C++)

Консольная игра «человек против ИИ», основанная на модификации Nim: **misère take-away game**.

## Правила

- В начале у крокодила **7 зубов**.
- Два участника — человек и ИИ — ходят по очереди.
- За один ход можно нажать **1 или 2** оставшихся зуба.
- Нажатые зубы обозначаются `[X]`, доступные — `[#]`.
- **Тот, кто нажимает последний зуб, проигрывает**.
- Ничья невозможна: на каждом ходу зубов становится меньше.

Зубы нажимаются условно слева направо; выбор конкретного зуба не меняет исход партии, поэтому игрок выбирает количество зубов, а не их номера.

## Требования

Компилятор C++ с поддержкой C++17, например GCC, Clang или MSVC. Сторонние библиотеки не нужны.

## Компиляция и запуск

Из директории проекта выполните:

### Windows (MinGW / g++)

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o crocodile.exe
.\crocodile.exe
```

### Linux / macOS

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o crocodile
./crocodile
```

### Visual Studio

Создайте проект **Console App** для C++, добавьте `main.cpp`, выберите стандарт C++17 и запустите проект.

## Как играть

1. Введите `1`, чтобы первым ходил человек, или `2`, чтобы первым ходил ИИ.
2. В свой ход введите `1` или `2` — количество зубов для нажатия.
3. Если остался один зуб, допустим только ход `1`.
4. После хода ИИ отображаются оценки Minimax и количество рассмотренных узлов дерева.
5. Игра завершается, когда остаётся 0 зубов. Нажавший последний проигрывает.

Текст консольного интерфейса на английском во избежание проблем с кодировкой в Windows Terminal / cmd.

## Примечание по исходному варианту Nim

Это **адаптация**, а не классический Nim: одна кучка из 7 зубов, ход 1–2, последний ход проигрышный. Если преподаватель требует именно исходные условия варианта 4 (несколько кучек, любое число камней, последний выигрывает), правила проекта необходимо предварительно согласовать.

# Crocodile Teeth — Minimax (C++)

Консольная игра «Человек против ИИ». На старте у крокодила **7 зубов**. Игроки по очереди нажимают **1 или 2 зуба**. Тот, кто нажал **последний зуб**, проигрывает. ИИ выбирает ход рекурсивным алгоритмом **Minimax** и выводит оценки доступных ходов и число просмотренных узлов дерева.

## Файлы

- `main.cpp` — исходный код игры.
- `REPORT.md` — краткий отчёт по лабораторной работе.

## Требования

Компилятор C++ с поддержкой C++17, например **g++** (MinGW-w64 / MSYS2 под Windows) или компилятор Microsoft Visual C++ (MSVC).

## Сборка и запуск в Windows PowerShell (g++)

Откройте папку проекта в VS Code, запустите **Terminal → New Terminal** и выполните:

```powershell
g++ -std=c++17 -O2 -Wall -Wextra -pedantic main.cpp -o crocodile.exe
.\crocodile.exe
```

> В PowerShell программа из текущей папки запускается через ` .\ ` (без пробелов). Просто `c` — не команда для запуска C++. Если PowerShell сообщает, что `g++` не найден, сначала установите компилятор MinGW-w64 (например, с помощью MSYS2) и проверьте путь к нему в PATH. Расширение Microsoft C/C++ для VS Code само по себе компилятор не устанавливает.

## Альтернатива: Microsoft Visual C++

В **Developer PowerShell for Visual Studio** (с установленными C++ Build Tools):

```powershell
cl /EHsc /std:c++17 main.cpp /Fe:crocodile.exe
.\crocodile.exe
```

## Linux / macOS (g++ или clang++)

```bash
g++ -std=c++17 -O2 -Wall -Wextra -pedantic main.cpp -o crocodile
./crocodile
```

## Как играть

1. В начале выбрать первого игрока: `1` — человек, `2` — ИИ.
2. Когда ход человека, ввести `1` или `2` (если остался один зуб, только `1`).
3. Ходы ИИ происходят автоматически с выводом оценок дерева.
4. Игра заканчивается, когда нажаты все зубы; проигрывает сделавший последний ход.

## Пример выигрышного ответа ИИ

Если человек ходит первым и нажимает **1** зуб, остаётся **6**. ИИ нажимает **2** зуба и оставляет **4** — проигрышную позицию для следующего игрока при оптимальной игре.

**Примечание:** позиция с 7 зубами проигрышна для начинающего при идеальной игре с обеих сторон. Поэтому если первым ходит ИИ, он не может гарантировать победу — это свойство правил, а не ошибка алгоритма.
